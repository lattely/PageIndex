# 原发性醛固酮增多症肾上腺静脉取血术专家共识

中国研究型医院学会高血压专业委员会

中国医疗保健国际交流促进会 外周动脉病学分会高血压介入诊治工作组

【摘要】 原发性醛固酮增多症（原醛症）是继发性高血压的常见病因，肾上腺静脉取血（AVS）是明确原醛症优势侧的金标准，对指导后续治疗策略有重要意义。AVS 是有创操作，在国内开展尚不普及。为了推动 AVS的普及与规范，中国研究型医院学会高血压专业委员会与中国医疗保健国际交流促进会外周动脉病学分会高血压介入诊治工作组总结了国内外循证医学证据与国内众多专家的操作经验，针对 AVS的意义、适应证、术前准备及操作流程与要点、并发症预防与处置及结果判读等进行了总结与更新，为 AVS 临床实践与发展提供全方位、贴近临床实际的指引，有力推动其普及化、规范化。

原发性醛固酮增多症（ primary aldosteronism，PA，简称原醛症）是继发性高血压的常见病因。有研究表明，在我国社区新诊断高血压人群中原醛症

患病率达4%以上［1］ ，国外报道患病率高达10%左右［2］ 。原醛症在高血压人群中的患病率随高血压程度递增［3］ ，在难治性高血压人群中国外有报道占17%\~23%［4-5］ ，我国一项研究显示难治性高血压中原醛症占比7.1%［6］ ，提示我国原醛症的患病率可能被低估。与血压水平相同的原发性高血压相比，原醛症会显著增加心血管风险［7］ ，且药物治疗原醛症面临严峻挑战［8］ 。因此，如何制订合理的诊疗策略是临床关注的焦点。随着对原醛症研究的深入及临床经验的积累，近年来国内外指南和共识对分侧肾上腺静脉取血术（ adrenal vein sampling，AVS）均予以高度重视，公认是判断肾上腺分泌醛固酮有无优势分泌侧的金标准，是指导治疗策略的关键检查［9］ 。但其适应证、检查规范、结果判读等存在认识不足。不同专业学会制订的指南、专家共识等关注重点有所不同，为了推动这项技术在我国临床上规范应用，特别是如何进行规范操作，减少并发症发生，本专家共识总结目前国内外AVS相关文献，结合专家操作经验，多学科参与，对AVS的适应证、操作流程、注意事项和结果判读方法进行总结制订本共识。

# 1 AVS的重要性和临床应用价值

原醛症的病因包括醛固酮瘤、特发性醛固酮增多症、原发性肾上腺皮质增生、分泌醛固酮的肾上腺皮质癌和家族性醛固酮增多症（包括Ⅰ型、Ⅱ型、Ⅲ型、Ⅳ型），以及极为罕见的异位醛固酮瘤。对于醛固酮瘤或单侧肾上腺皮质增生导致的原醛症，行优势侧肾上腺切除后血钾水平能够恢复正常，而30%\~60%患者血压下降或完全恢复正常［10］ 。在醛固酮瘤中，直径小于1 cm的腺瘤不在少数，对于直径小于1 cm的醛固酮瘤CT的诊断效率仅为60%\~70%［11］ 。尽管指南［12］ 认为特发性醛固酮增多症和糖皮质激素可抑制性醛固酮增多症的患者首选药物治疗，但对于有明确优势侧的患者，手术治疗为首选。一项荟萃分析比较了手术治疗与药物治疗对于原醛症患者预后的差异，发现接受手术治疗的患者全因死亡、冠心病、心房颤动和心力衰竭的风险均较药物治疗组下降［13］ 。为了进一步优化原醛症患者的治疗，确认肾上腺有无优势分泌侧具有重要意义。AVS是明确原醛症患者肾上腺有无优势分泌侧的重要检查方法，在有经验的中心确定优势侧分泌的符合率为89.6%\~96.6%［14］ ，是原醛症分型诊断的“金标准”。AVS是有创检查，结果准确性基于醛固酮和皮质醇水平的准确测定，因此建议在已建立稳定、准确的皮质醇及醛固酮检测方法的单位开展AVS。此外，由于右侧肾上腺静脉（rightadrenal vein，RAV）呈锐角直接汇入下腔静脉且发出点存在诸多变异，成功完成导管到位与取血难度较高，经验丰富的中心AVS成功率大于90%［15］ ，推荐各中心由经过培训合格的、AVS经验丰富的固定医师完成该操作，以提高检查成功率［16］ 。

【建议1】已建立稳定、准确的醛固酮及皮质醇检测方法的单位可开展AVS，建立多学科协作团队，以保证AVS结果正确解读。

【建议2】推荐各中心由经过培训的AVS经验丰富的固定医师完成AVS，以提高检查成功率。

# 2 AVS的适应证

AVS的主要目的是明确原醛症患者肾上腺有无优势分泌侧。既往国外指南认为AVS适用于：（1）原醛症诊断；（2）具有手术意愿及手术条件；（3）肾上腺影像学提示单侧或双侧肾上腺增生或腺瘤。同时符合上述三者可考虑行AVS［17］ 。近期国外指南将原醛症根据组织学及免疫组织化学染色（主要为CYP11B2阳性）分为醛固酮瘤（直径≥1 cm）、醛固酮分泌的结节（＜1 cm）、醛固酮分泌的微结节（＜1 cm且苏木素-伊红染色无法鉴别）、醛固酮分泌的多发微结节、醛固酮分泌的弥漫增生［18］ 。新分型中各亚型均可能出现优势侧分泌情况，临床上也有越来越多的影像学肾上腺形态正常的原醛症患者出现优势侧分泌，并通过经皮超选择肾上腺动脉栓塞术获得生化学缓解［19］ 。因此，原醛症患者的影像学表现可能不是决定是否需行AVS的依据。

既往国外原醛症指南认为以下几种情况不建议行AVS检查［17］ ：（1）年龄小于40岁，肾上腺影像学示单侧腺瘤且对侧肾上腺正常的患者；（2）肾上腺手术高风险、不适合手术的患者；（3）影像学怀疑肾上腺皮质癌的患者；（4）已经证实患者为糖皮质激素可抑制性醛固酮增多症（家族性醛固酮增多症Ⅰ型）或家族性醛固酮增多症Ⅲ型；（5）其他不能耐受AVS的情况（如对比剂过敏、不能维持平卧体位等）。小于40岁可以不进行AVS是基于早期文献显示这些患者的AVS的优势侧结果与影像学的单侧异常高度匹配［20］ 。然而，近期一项总结了2023年以前发表的小于35岁的原醛症患者的综述显示，在共计66例小于35岁的、影像学单侧病变的原醛症患者中，AVS证实为双侧分泌、无优势侧的有7例（10.6%）［21］ ，提示影像学单侧病变低龄患者单纯基于影像学判断优势侧可能不准确。此外，已有病例报道了分泌醛固酮的肾上腺皮质癌患者可能不会表现出典型的恶性肿瘤影像学特征，此时AVS对治疗决策仍有价值［22］ 。综上，有手术或介入治疗意愿的原醛症患者，可考虑进行AVS协助判

断优势侧。

# 3 取血准备

# 3. 1 手术适应证确认和风险评估

术前需了解患者凝血功能、血常规等结果，评估有无手术禁忌。建议术前完善肾上腺增强CT检查，以初步评估双侧肾上腺静脉、尤其是RAV开口位置及走行方向［26］ ，有条件的单位可行肾上腺静脉三维重建。但仍有肾上腺CT难以清晰显示RAV开口可能［27］ 。向患者交代手术相关注意事项及风险，签署操作知情同意书。一些研究发现原醛症的患者合并亚临床Cushing综合征的发生率高达21%，这种共分泌多见于肾上腺腺瘤体积较大和患者年龄较大的情况［28］ 。皮质醇异常分泌会影响AVS结果判读准确性。因此，除了确认患者原醛症诊断以外，皮质醇节律紊乱的患者需行过夜地塞米松抑制试验以除外Cushing综合征。为了减少地塞米松对肾上腺静脉采血量与皮质醇水平的影响，过夜地塞米松抑制试验需在AVS前至少48 h进行。

# 3. 2 调整降压药物、电解质

原醛症患者行肾素、醛固酮检测和确诊试验时需停用血管紧张素转换酶抑制剂（angiotensinconverting enzyme inhibitor，ACEI）、血管紧张素Ⅱ受体拮抗剂（angiotensin Ⅱ receptor blocker，ARB）及β受体阻滞剂类降压药2周，停用利尿剂［包括盐皮质激素受体拮抗剂（mineralocorticoidreceptor blockade，MRA）］4周，推荐降压药物调整为非二氢吡啶类钙拮抗剂及α受体阻滞剂［29］ 。然而，针对AVS检查，研究显示MRA能够升高肾素和醛固酮水平，但全身用药未显示出对优势侧判断的影响［30-31］ 。故临床上对于已确诊原醛症、拟行AVS的患者，可以不严格要求停用MRA。术前尽量将血钾补充至3.5 mmol/L以上（长期明显低钾、补钾困难者3.0 mmol/L以上），以避免严重低钾血症对醛固酮的抑制作用［32］ 。

# 3. 3 体位

术前1 h患者采取平卧位、心情平静，保持体位不变，平车送入导管室。应激往往发生在开始AVS操作时，随着皮质醇水平的升高，通过皮质醇对肾上腺静脉取血是否成功的判断和优势侧判断均会受到影响，故避免应激和保持体位非常重要［33］ 。

【建议4】AVS术前应完善肾上腺影像学检查，并仔细读片判断肾上腺静脉走行。首选肾上腺多期增强CT，无法完成者可用肾上腺平扫CT或肾上腺磁共振扫描替代。

【建议5】皮质醇节律紊乱的原醛症患者需在AVS前除外Cushing综合征。

【建议6】AVS手术当日清晨需平卧位1 h以上，平车送入导管室。

# 4 操作流程

# 4. 1 肾上腺静脉解剖

肾上腺静脉两侧各1支，又称为中央静脉。左侧肾上腺静脉经过整个左肾上腺纵轴，长1\~4 cm，直径4\~5 mm，向下与膈下静脉共干后，通常在脊柱左侧约1 cm处汇入左肾静脉。RAV常向尾侧成角，长1\~15 mm，直径3.5\~5 mm。RAV或可为双支，极少情况下可为3支，分支静脉可能汇入膈下或右肾静脉，但多数情况下有1支肾上腺静脉进入下腔静脉［34］ 。RAV形态多变，国外有中心将其总结为5种［35］ 。（1）腺体型，由一中央主干及许多分支组成；主干与分支间夹角小于90°，形成一特征性的腺体样结构。偶尔与副肝静脉较难鉴别。（2）呈delta形，其内部无明显的分支结构。（3）三角形，血管密集呈毛刷样改变。（4）不定型，肾上腺血管较难辨认，但主要血管位置和方向具有特征性，并与CT表现位置符合。（5）蜘蛛型，1支肾上腺静脉及其星状或蜘蛛状稀疏分支。少数RAV可汇入肝静脉、右肾静脉（图1）。术前肾上腺增强CT有助于对双侧肾上腺静脉走行及RAV开口位置进行评估，提高手术操作的成功率［36］ 。RAV形态短小，解剖变异较大，根据RAV开口及走行将RAV大致分为三型（图4）：Ⅰ型，RAV独立开口于下腔静脉，向右后方走行，此型最为常见；Ⅱ型，RAV独立开口于下腔静脉，但向左后方或正后方走行；Ⅲ型，RAV汇入副肝静脉，或RAV、副肝静脉共同汇合于下腔静脉。研究报道类似RAV-Ⅲ型解剖变异比例约为12.1%，此型RAV开口隐蔽，易被术者忽略，插管最为困难（图5），并且采集血样易被邻近副肝静脉血液稀释［37］ 。AVS操作医师在术前应仔细判读CT影像信息，仔细分析RAV汇入下腔静脉的位置、方向，有

# 4. 3 AVS操作及注意事项

# 4. 3. 1 AVS操作流程

患者由平车保持平卧位直接转移至导管室床，常规消毒、铺巾，根据选择的入路消毒腹股沟区和（或）上肢肘部（一般为右上肢）。

（1）入路选择。①右侧肘前静脉：右侧肘前静脉（包括肘正中静脉或贵要静脉）通路采血与RAV同轴性更好，可提高RAV取血的成功率，缩短取血所需的时间。可由护士提前无菌操作留置20 G（或更粗大）留置针。术中再次充分消毒后以桡动脉穿刺针穿刺留置针尾端，导入桡动脉鞘导丝，后撤出留置针，沿导丝送入5 F/6 F桡动脉鞘。亦可术中穿刺，部分肘静脉显露不清楚或有解剖变异穿刺有困难时，术中可在彩色多普勒超声引导下完成静脉穿刺。操作时需注意导丝引入和进鞘的通顺性，遇到阻力不可强行操作，必要时可在X线透视下操作。②股静脉：以此入路右侧取血难度增加（表1），多在上肢静脉入路无法建立时采用。穿刺方法与常规股静脉穿刺一致，留置5 F/6 F鞘管。有条件的医院建议超声引导穿刺，降低并发症发生风险。近期有研究比较了经肘前静脉和经股静脉入路AVS，发现取血成功率、并发症发生率及术后随访结果无差异。经肘前静脉同步AVS术式X线曝光时间短、患者舒适度高。故更推荐经肘前静脉入路［40］ 。

（2）经鞘管送入导管寻找两侧肾上腺静脉，完成采血。

①如经上肢静脉操作，右侧首选4 F/5 F MPA 1导管，左侧可选择5 F TIG、JL 4等导管。在0.035 in（1 in=2.54 cm）导丝引导下，操作导管到达下腔静脉第1腰椎水平处。①RAV插管：依据CT提供RAV走行信息，操作MPA 1导管，发现导管有“勾挂”、“跳跃”现象时，再轻轻调整导管，在X线透视下观察导管尖端稳定后，回抽见血后缓慢注射少量对比剂，通过正位、右前斜位30°等体位造影，显示RAV。②左侧肾上腺静脉插管：先操作导管进入左肾静脉，继续旋转推送导管使导管尖端缓慢爬升，即可于左肾静脉上缘进入左肾上腺总干静脉。缓慢注射1\~2 ml对比剂显示左肾上腺总干静脉、左膈下

静脉、左侧肾上腺静脉。继续操作导管或在导丝引导下，导管可超选择进入左侧肾上腺静脉。回抽见血后缓慢注射少量对比剂可确认导管位置。

②如经股静脉操作，右侧可选择JR 4、Simmons 1、Simmons 2和Cobra 2等导管，左侧可选择JR 4、Simmons 2等导管。应用Simmons导管进行RAV取血操作时，因Simmons导管的反转形态，需要注意导管操作与常规导管不同：在体外往内推送导管时，导管头端从肾上腺静脉往上脱出；当在体外往外拉导管时，导管头端往RAV内深插。余导丝导管操作技巧与上肢静脉类似。

③对于RAV-Ⅲ型患者，先插管至副肝静脉，采取边后退边顺时针旋转导管的方式，或专注于副肝静脉开口附近，寻找并插管至RAV。取血后可再次造影以明确是否发生移位，可进一步提高AVS成功率。操作过程中，必要时可用导丝和微导管辅助。

（3）在采血开始前和结束时经鞘管或导管采外周血或下腔静脉血作对照。采血结束后拔除鞘管，压迫5 min，止血后纱布包扎，胶带固定，穿刺处关节制动6 h。

（4）同步AVS：鉴于肾上腺皮质激素分泌存在波动性［49］ ，以及操作不熟练可能导致两侧肾上腺静脉取血时间相隔过长，可能导致取血结果不准确，而同步AVS可以避免上述情况［50］ ，有条件的中心可考虑行同步AVS。传统的同步采血需要穿刺两个股静脉入路，增加患者痛苦与穿刺风险。我国学者探索了经肘静脉同步AVS［37］ ，流程如下：选择合适静脉血管作为导管入路（通常选用2根贵要/头静脉或1根贵要静脉+1根头静脉），可在靶血管预先留置20 G套管针，术中更换为5 F/6 F鞘管；亦可在术中穿刺（方法同上）。在0.035 in导丝引导下，操作2根导管到达下腔静脉第1腰椎水平处备用。先后完成左侧肾上腺静脉插管和RAV插管，两根导管均到位后，同步进行双侧采血并送检。

# 4. 3. 2 AVS操作注意事项

（1）非同步采血时，因RAV变异大，血管内径更小，难度更大，往往耗时较长，非同步采血时建议先行RAV取血，然后再做左侧肾上腺静脉取血，以此减少双侧采血的间隔。  
（2）注射对比剂时注意注射前先回抽见血、注射时需低压力缓慢推注，避免造成静脉血管及肾上腺损伤。取血时前2\~3 ml血液建议弃去，以去除导管内残留的对比剂或上一位置的血液的影响。如有可能，建议让肾上腺静脉内血液自然流出，可有效避免由于负压回抽带来的静脉损伤和下腔血液回流导致的取血失败。  
（3）有的中心为了减少术中导管血栓的风险，会在术前给予补液［51］ ，但补液会影响醛固酮分泌，可能影响取血结果，并不推荐应用。为减少血栓风险，可术中予少量肝素（1 000\~3 000 U或50\~100 U/kg）抗凝。  
（4）若CT显示有腺瘤时，适当增加对比剂推注量，使腺瘤充分显影。必要时可考虑进行分段采血，即除正常位置采血外，在尽可能接近腺瘤的专属血管或交通血管处采血，以明确腺瘤是否有分泌功能。若血管较细，可选用4 F导管或者联合微导管。  
（5）非ACTH激发取血时间应在上午8\~10点，如其他时间取血建议ACTH激发，避免激素分泌波动。  
（6）低钾血症对醛固酮分泌有较强抑制作用，注意术前补钾，尽量维持血钾在正常范围。

# 4. 4 术中推荐取血点

左侧：左侧肾上腺静脉解剖结构上多有左膈下静脉汇入，故置管后应用少量对比剂时往往可呈现“Y”字形，提示置管成功，可进行左侧肾上腺静脉取血。目前国际指南对左侧肾上腺静脉取血位置推荐尚不一致，美国和日本内分泌学会指南分别推荐于共干静脉和肾上腺静脉取血［11，52］ 。既往多项回顾性研究均提示共干静脉及肾上腺静脉的醛固酮/皮质醇比值差异无统计学意义，一致性好。然而有研究发现，在肾上腺共干静脉取血失败率较肾上腺静脉高［53-54］ 。为了提高取血结果准确性，可考虑共干静脉及肾上腺静脉均取血，对于无法行肾上腺静脉取血者，可行共干静脉取血。

右侧：RAV取血相对困难，由于直接汇入下腔静脉，且起源多变，易与副肝静脉、肾被膜静脉、椎体静脉、肋间静脉等混淆，需仔细鉴别［33］ 。置管后轻柔推注对比剂后呈现肾上腺形态显影，一定程度上可提示RAV置管成功，但在下腔静脉到右肾静脉之间上下多部位尝试置管并进行取血，是保障RAV取血成功的重要手段［55］ 。对于RAV-Ⅲ型患者，可先寻找副肝静脉，先插管至副肝静脉，采取边后退边顺时针旋转导管的方式，或专注于副肝静脉开口附近，寻找并插管至RAV。

结合文献及国内各中心经验，以下几点提示有助于术中RAV识别。

（1）RAV的开口基本位于第10胸椎至第1腰椎区间，也有低至第1腰椎以下，但是绝大部分位于第11胸椎和第12胸椎之间。RAV开口大部分水平位置距右侧肾脏上缘一个肋间隙距离。  
（2）67%\~86%的RAV开口与下腔静脉远端呈锐角，即开口向下或向右下［56］ 。  
（3）95%以上的RAV开口位于下腔静脉侧后方［56］ 。  
（4）RAV造影显示以下两种影像时多提示插管到位：①腺体型、实三角型、空三角型等易辨认的血管形态；②不规则的血管形态，但伴有右肾包膜静脉显影。  
（5）RAV造影时，下导静脉显影也可作为是RAV插管成功标志。下导静脉是由肾上腺皮层发出的位于肾上腺侧面、内侧或下方的浅表血管，在右侧不同于沿上方走行的副肝静脉，它们从肾上腺表面延伸至肾周脂肪，与右肾静脉、肋间静脉、膈静脉、奇静脉、副奇静脉或下腔静脉相通。  
（6）RAV解剖变异大是导致取血失败的重要原因，除了典型静脉分布外，也要重视不典型的形态。下导静脉、肾包膜静脉、副肝静脉等的识别可提高RAV取血成功率。必要时可通过右前斜位30显影判断RAV和下腔静脉关系进一步判断是否为RAV。  
（7）RAV开口的大部分水平位置接近左侧肾上腺静脉最远端的水平位置，因此左侧肾上腺静脉的位置可以尝试用于引导RAV定位［57］ 。  
（8）术中即刻快速皮质醇测定有助于确定是否

取血成功［58］ 。如术中采血成功存疑，建议AVS术中使用全自动化学发光免疫分析仪进行床旁皮质醇检查，取血后立即进行皮质醇检查，10 min左右出结果，可以及时准确地判断取血是否成功，明显提高AVS成功率。肾上腺静脉取血成功定义为肾上腺血样皮质醇与外周血样皮质醇比值≥2。

# 4. 5 术后并发症及处理

作为一种有创操作，AVS的并发症包括肾上腺静脉破裂、肾上腺静脉栓塞和肾上腺梗死等，进而可能导致急性肾上腺皮质功能减退，甚至肾上腺危象，还有应用对比剂导致的对比剂肾病等，罕见并发症包括肺栓塞等［15］ 。AVS术后并发症发生率在各中心报道均不相同，约0.2%\~10%［16］ 。

肾上腺静脉破裂虽风险较低，手术操作过程中务必保持导管操作、对比剂推注轻柔，避免粗暴操作。临床上应格外重视术后当日或次日出现急性腹痛的情况，及时排查肾上腺静脉破裂、肾上腺静脉栓塞可能。肾上腺静脉破裂大部分可以通过保守治疗，严密观察即可，如不能缓解，可考虑应用介入栓塞治疗。同时关注肾上腺激素尤其是糖皮质激素分泌情况，警惕肾上腺皮质功能减退症发生。对比剂肾病方面，AVS过程中对比剂用量较少。对于一些既往存在肾功能不全的患者，术后适当水化可能避免对比剂肾病的发生，尽量避免术前生理盐水水化对醛固酮分泌造成影响。

【建议7】在AVS术前需完善肾上腺影像学评估，AVS术者需充分读片分析双侧肾上腺静脉走行。

【建议8】可选择非同步或同步 $\mathrm { A V S } , \mathrm { A C T H } _ { 1 - 2 4 }$ 激发或非 $\mathrm { A C T H } _ { 1 - 2 4 }$ 激发的操作方式。如未进行$\mathrm { A C T H } _ { 1 - 2 4 }$ 激发，AVS操作需在上午进行。

【建议9】推荐优选上肢静脉通路进行AVS。

【建议10】AVS术中导丝、导管及注射对比剂操作需规范、轻柔。术后腹痛需警惕肾上腺静脉破裂或肾上腺静脉栓塞、肾上腺梗死，进而导致急性肾上腺皮质功能减退，甚至肾上腺危象的可能。

# 6 总结与展望

AVS是原醛症患者明确优势分泌的金标准。随着各中心AVS技术的成熟，成功率高的中心可以逐渐将AVS作为原醛症患者的常规诊疗手段，AVS能够为原醛症患者的优势侧分泌，甚至通过超选择AVS为肾上腺局部的激素分泌量提供重要临床信息，以综合评估后续治疗方案。原醛症无论从分型、解剖结构和内分泌功能角度越来越显示出异质性，AVS仅区分左侧或右侧优势分泌不能完全满足临床需要，后续根据肾上腺影像学在肾上腺静脉的主要属支内进行超选择AVS，有可能提供更精细的原醛症结构和功能分型，展现疾病全貌。AVS研究方兴未艾，随着操作流程的改善和新技术研发对AVS成功率的提高，AVS将为原醛症患者获得尽可能多的临床信息，以指导精准治疗。
